Sorting the walkers by place

Each walker's state lives in a slot, and the slots are in no order: a GPU warp of 32 walkers reads memory from all over the map. Once a game second the prototype moves every slot so living walkers sit in the order of their 8x8-cell tile, and empty slots after them. Same rules; a sorted run is a different run of them, so it is checked on paired seeds.

Recommendation

Build the sort, on the GPU: a stable counting sort by tile, then a gather of each per-slot buffer, every few frames. It cut the simulation step's GPU time by 44% on planet 8 and plays the same within what seven pairs can show.

  • Locality decays within a second, mostly from births landing in random slots: sort often, or birth into a free slot near the parent.
  • On planet 8 only a quarter of the slots live: a 1070 run that only packs the living is asked of Engine, to split the win.
