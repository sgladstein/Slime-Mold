# Project-memory notes about the mould game (snapshot, 2026-11-10)

The Pixel Physics project on claude.ai kept a shared memory: one note per
subject, read by every session before it started work. These are the notes
about the mould game and the brainstorm it came from, plus three standing
owner rulings that shaped how it was measured and shown, copied as they
stood when the game moved to a new account.

They are a snapshot. Message ids (`cmsg_...`) and thread names point into
the old project and will not open from the new one; artifact links
(`claude.ai/artifact/...`) belong to the old account, and every page they
name is copied into `Reports/` (see `Reports/pages.md`). Where a note and
the code disagree, the code wins.
