When the owner asks for a brainstorm about a new game direction (the RTS, for example), don't hand the agents the demo's current toolbox (lamp, oats, salt, knife, water) as the levers to map onto. Those tools were built for a single-player herding puzzle. On 2026-11-10 the owner noticed that every RTS brainstorm agent had re-used them and asked for a real exploration instead.

**Why:** briefs that list the tools anchor every idea on them, and the brainstorm narrows to tuning the existing demo.

**How to apply:**
- Describe the *model* in neutral terms: walkers, trail, scent, food, store, tube, sleep, walls, two populations.
- Say outright that the old tools may come back only if they win on merit.
- Have the agents generate many ideas before judging any.
- Keep them off the dish code and earlier design docs until the end.

See [[rts-direction]].
