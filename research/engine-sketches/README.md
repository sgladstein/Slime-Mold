# Engine sketches

`mould_world_sketch.rs.txt` is `examples/mould_world_sketch.rs` from
Pixel_Physics (2026-11-09, `Reports/mould-real-world-2026-11-09.md`): the
shipped mould dropped into a side-on slice of the lab box and onto a
top-down forest floor. It needs the falling-sand engine *and* the mould
model in one crate, so it compiles in neither repo after the split; it is
kept for reading. To run it, check out Pixel_Physics at `ca6b08f6` (main
on 2026-11-10, the last commit before the mould left) and use the command
in its header.
