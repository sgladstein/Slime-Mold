# GDC 2009 Game Design Workshop handout (feedback systems, drama)

Negative feedback drives a system to a stable state, positive to an unstable
one (the snowball). "A game system that gives the winning player an advantage
will drive the players further apart"; helping the loser drives them closer.
Drama from uncertainty and inevitability: "A non-renewable resource can create
the sense of forward progress", and its depletion rate predicts game length.
