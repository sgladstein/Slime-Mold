# Sources: the outside material behind the mould game

One card per external source: what it is, how fully it was read, where any
local copy is, its licence, the facts we use with page refs, and which
reports use it. Reports hold the long readings; cards are the index into
them and survive claude.ai links going dead. Started 2026-11-10 (owner asked
how to keep the sources available to other agents).

**Rules**
- Add a card when a report first relies on a source; update `read:` when it
  is read further. Never put a number on a card that is not in the source.
- Keep a copy only where the repo may: papers and saved pages here are for
  reading in this private repo, not redistribution. Never copy GPL or NC
  code into `src/` (our code is proprietary, `LICENSE`); MIT code may be
  reused with its notice.
- Beside every PDF copy, keep a `.txt` extraction so agents can search it;
  beside GIFs, a contact sheet.
- Sites that refuse automated reading (Jenson's) are read from the owner's
  saved copy, never through a mirror.
